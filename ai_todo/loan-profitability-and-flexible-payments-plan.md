## What We're Building

### 1. Dynamic KPI Cards (All Loans vs Individual Loan Filter)
Currently in `LoanApplication.tsx`, top cards (`Active Loans`, `Outstanding Balance`, `Next Due`) always calculate across all loans, while only `Net Profit` reacts to the selected loan.
- **When "All Loans" is selected**:
  - `Active Loans`: Total active loans count.
  - `Outstanding Balance`: Sum of remaining balances across all loans.
  - `Next Due`: Earliest upcoming payment due date and amount across all loans.
  - `Net Profit`: Total farm income minus total farm expenses across all loans.
  - `Profitability / ROI`: Combined Net Profit / Combined Total Loan Obligation.
- **When a specific loan is selected (`selectedLedgerLoanId !== "all"`)**:
  - `Active Loans`: `1` (if active) or `0` (if completed/pending).
  - `Outstanding Balance`: That specific loan's remaining balance.
  - `Next Due`: That specific loan's next installment due date and amount.
  - `Net Profit`: Net profit generated by that specific loan (`loanIncome - loanExpenses`).
  - `Profitability / ROI`: Specific loan's Net Profit / Specific loan's Total Repayment (`principalAmount + totalInterest`).

### 2. New KPI Card: Loan Profitability & ROI Status
- **Formula**: `ROI % = (Net Profit / Total Loan Repayment) * 100%`
- **Badges & Visual States**:
  - `ROI >= 100%`: **Profitable** (Emerald green badge, e.g. `+140% Profitable`) — farm earnings have exceeded the total cost of the loan.
  - `0% <= ROI < 100%`: **Recovering / Break-Even Tracking** (Amber badge, e.g. `65% On Track`) — farm earnings are paying down the loan obligation.
  - `ROI < 0%`: **Deficit / Unprofitable** (Rose red badge, e.g. `-15% Deficit`) — farm expenses currently exceed income.

### 3. Use Posted Income Directly as Loan Payment
- In the Income & Expenses tab:
  - When viewing income entries, each income row includes an action button: **"Apply as Loan Payment"**.
  - In the "Add Income" modal, a toggle: **"Apply this income towards loan payment"**.
  - When confirmed:
    1. Records payment in `loanPayments` linked to the active loan and installment.
    2. Records a matching expense entry in `loanIncomeExpenses` (`category: "Loan Payment"`, description: `Auto-payment deducted from farm harvest/sales income: [description]`).
    3. Deducts from loan `remainingBalance` and increases `totalPaid`.
    4. Automatically updates ledger totals and loan progress in real time.

### 4. Full Balance Payoff (Lump-Sum Early Settle)
- In the payment modal for both individual and cooperative loans:
  - Add a one-click **"Pay Off Full Remaining Balance (₱X,XXX)"** option.
  - Settles all remaining unpaid schedule installments.
  - Marks loan `status: "completed"`, `remainingBalance: 0`, and records total repayment audit log.

### 5. Flexible Custom Payment Amounts (Higher or Lower)
- Replace static fixed installment input with flexible amount controls:
  - Quick chips: `[Exact Due: ₱X,XXX]`, `[Custom Amount]`, `[Full Payoff: ₱X,XXX]`.
  - **Lower Amount (Cash Strapped)**: Marks payment as `partial`, updates `remainingBalance`, logs notes.
  - **Higher Amount (Extra Money)**: Credits excess amount against remaining loan principal balance, accelerating payoff.

## Implementation Tasks

### Task 1: Update Top KPI Metrics to be Fully Reactive to Filter in `LoanApplication.tsx`
Update KPI computations so that selecting a loan in the ledger tab or hero card filters `activeLoansCount`, `totalOutstanding`, `nextDueDate`, and computes the new `loanRoiPercentage` and `roiStatus`.

- **File**: `src/pages/LoanApplication.tsx` [MODIFY]
- **Exact Logic**:
```typescript
  // Dynamically scoped loan KPI metrics based on selectedLedgerLoanId
  const scopedLoans = useMemo(() => {
    if (activeTab === "income_expenses" && selectedLedgerLoanId !== "all") {
      return loans.filter((loan) => loan.id === selectedLedgerLoanId);
    }
    return loans;
  }, [loans, activeTab, selectedLedgerLoanId]);

  const scopedActiveLoansCount = scopedLoans.filter((l) => l.status === "active").length;
  const scopedTotalOutstanding = scopedLoans.reduce((s, l) => s + (l.remainingBalance || 0), 0);
  const scopedTotalObligation = scopedLoans.reduce((s, l) => s + (l.totalRepayment || (l.principalAmount + (l.totalInterest || 0))), 0);

  const scopedNextDuePayment = useMemo(() => {
    const activeScopedLoanIds = new Set(scopedLoans.filter(l => l.status === "active").map(l => l.id));
    const upcomingPayments = payments
      .filter((p) => activeScopedLoanIds.has(p.loanId) && (p.status === "upcoming" || p.status === "overdue"))
      .sort((a, b) => new Date(a.dueDate).getTime() - new Date(b.dueDate).getTime());
    return upcomingPayments[0] || null;
  }, [scopedLoans, payments]);

  // ROI / Profitability Formula: Net Profit / Total Loan Repayment
  const profitabilityMetrics = useMemo(() => {
    if (scopedTotalObligation <= 0) {
      return { ratio: null, label: "No Loan Obligation", color: "text-slate-500", bg: "bg-slate-50 border-slate-200" };
    }
    const ratio = Math.round((displayedNetProfit / scopedTotalObligation) * 100);
    if (displayedNetProfit >= scopedTotalObligation) {
      return { ratio, label: "Profitable", color: "text-emerald-700", bg: "bg-emerald-50 border-emerald-200" };
    }
    if (displayedNetProfit > 0) {
      return { ratio, label: "Recovering / On Track", color: "text-amber-700", bg: "bg-amber-50 border-amber-200" };
    }
    return { ratio, label: "Deficit / Unprofitable", color: "text-red-700", bg: "bg-red-50 border-red-200" };
  }, [displayedNetProfit, scopedTotalObligation]);
```
